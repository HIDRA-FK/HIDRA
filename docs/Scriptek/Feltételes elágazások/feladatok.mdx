## 1. Pozitív, nulla vagy negatív

 Feladat

Kérj be a felhasználótól egy számot.  
Vizsgáld meg, hogy a megadott szám pozitív, nulla vagy negatív.  
A program ennek megfelelő szöveget írjon ki.

 Expected output példa 1

```bash
Adj meg egy számot:
8
A szám pozitív.
````

 Expected output példa 2

```bash
Adj meg egy számot:
0
A szám nulla.
```

 Expected output példa 3

```bash
Adj meg egy számot:
-4
A szám negatív.
```

<details>
<summary>Megoldás</summary>

```bash
#!/bin/bash

echo "Adj meg egy számot:"
read szam

if [ $szam -gt 0 ]
then
    echo "A szám pozitív."
elif [ $szam -eq 0 ]
then
    echo "A szám nulla."
else
    echo "A szám negatív."
fi
```

</details>

## 2. Jegy értékelése

 Feladat

Kérj be a felhasználótól egy jegyet.
A program írja ki, hogy a jegy milyen minősítésnek felel meg.
Az 5 legyen jeles, a 4 jó, a 3 közepes, a 2 elégséges, minden más esetben elégtelen jelenjen meg.

 Expected output példa 1

```bash
Adj meg egy jegyet:
5
Jeles.
```

 Expected output példa 2

```bash
Adj meg egy jegyet:
3
Közepes.
```

 Expected output példa 3

```bash
Adj meg egy jegyet:
1
Elégtelen.
```

<details>
<summary>Megoldás</summary>

```bash
#!/bin/bash

echo "Adj meg egy jegyet:"
read jegy

if [ $jegy -eq 5 ]
then
    echo "Jeles."
elif [ $jegy -eq 4 ]
then
    echo "Jó."
elif [ $jegy -eq 3 ]
then
    echo "Közepes."
elif [ $jegy -eq 2 ]
then
    echo "Elégséges."
else
    echo "Elégtelen."
fi
```

</details>

## 3. Életkor alapján kategória

 Feladat

Kérd be a felhasználó életkorát.
Ha a megadott kor 14-nél kisebb, akkor a program írja ki, hogy gyerek.
Ha 14 vagy annál nagyobb, de 18-nál kisebb, akkor írja ki, hogy tini.
Minden más esetben írja ki, hogy felnőtt.

 Expected output példa 1

```bash
Hány éves vagy?
10
Gyerek vagy.
```

 Expected output példa 2

```bash
Hány éves vagy?
16
Tini vagy.
```

 Expected output példa 3

```bash
Hány éves vagy?
22
Felnőtt vagy.
```

<details>
<summary>Megoldás</summary>

```bash
#!/bin/bash

echo "Hány éves vagy?"
read kor

if [ $kor -lt 14 ]
then
    echo "Gyerek vagy."
elif [ $kor -lt 18 ]
then
    echo "Tini vagy."
else
    echo "Felnőtt vagy."
fi
```

</details>

## 4. Két szám összehasonlítása

 Feladat

Kérj be a felhasználótól két számot.
Hasonlítsd össze őket.
A program írja ki, hogy az első szám nagyobb, a második szám nagyobb, vagy a két szám egyenlő.

 Expected output példa 1

```bash
Add meg az első számot:
9
Add meg a második számot:
4
Az első szám nagyobb.
```

 Expected output példa 2

```bash
Add meg az első számot:
2
Add meg a második számot:
7
A második szám nagyobb.
```

 Expected output példa 3

```bash
Add meg az első számot:
5
Add meg a második számot:
5
A két szám egyenlő.
```

<details>
<summary>Megoldás</summary>

```bash
#!/bin/bash

echo "Add meg az első számot:"
read a

echo "Add meg a második számot:"
read b

if [ $a -gt $b ]
then
    echo "Az első szám nagyobb."
elif [ $a -lt $b ]
then
    echo "A második szám nagyobb."
else
    echo "A két szám egyenlő."
fi
```

</details>

## 5. Hónap száma alapján évszak

 Feladat

Kérj be a felhasználótól egy hónap számát 1 és 12 között.
A program határozza meg, hogy az adott hónap melyik évszakhoz tartozik, majd írja ki az évszak nevét.

 Expected output példa 1

```bash
Adj meg egy hónap számot 1 és 12 között:
1
Tél van.
```

 Expected output példa 2

```bash
Adj meg egy hónap számot 1 és 12 között:
4
Tavasz van.
```

 Expected output példa 3

```bash
Adj meg egy hónap számot 1 és 12 között:
7
Nyár van.
```

 Expected output példa 4

```bash
Adj meg egy hónap számot 1 és 12 között:
10
Ősz van.
```

<details>
<summary>Megoldás</summary>

```bash
#!/bin/bash

echo "Adj meg egy hónap számot 1 és 12 között:"
read honap

if [ $honap -eq 12 ]
then
    echo "Tél van."
elif [ $honap -le 2 ]
then
    echo "Tél van."
elif [ $honap -le 5 ]
then
    echo "Tavasz van."
elif [ $honap -le 8 ]
then
    echo "Nyár van."
else
    echo "Ősz van."
fi
```

</details>
