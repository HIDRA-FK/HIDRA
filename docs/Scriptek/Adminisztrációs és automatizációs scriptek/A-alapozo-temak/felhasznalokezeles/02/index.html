Felhasználó automatikus létrehozása alapjogosultságokkal

Bevezetés​

Ebben az anyagban egy olyan Bash scriptet készítünk, amely egy új Linux felhasználót hoz létre. A script nemcsak magát a felhasználót készíti el, hanem hozzárendeli egy megadott csoporthoz, létrehozza a home könyvtárát, beállítja a Bash shellt, majd megadja a szükséges alapjogosultságokat is.

Ez a megoldás sokféle helyzetben használható. Például akkor, amikor egy rendszerben új felhasználónak kell hozzáférést adni, amikor egységes szabályok szerint szeretnél új fiókokat létrehozni, vagy amikor a kézi adminisztrációt szeretnéd automatizálni.

Tesztkörnyezet létrehozása​

A gyakorláshoz először készíts egy egyszerű tesztkörnyezetet.

Hozz létre egy új fájlt:

nano uj_felhasznalo.sh

Mentsd bele a scriptet, majd tedd futtathatóvá:

chmod +x uj_felhasznalo.sh

Ezután rendszergazdai jogosultsággal futtasd:

sudo ./uj_felhasznalo.sh

A futtatás után ezekkel a parancsokkal tudod ellenőrizni az eredményt:

id felhasznalo01
ls -ld /home/felhasznalo01
grep felhasznalo01 /etc/passwd
getent group felhasznalok
Ez a tesztkörnyezet arra szolgál, hogy a scriptet biztonságosan kipróbáld, és ellenőrizni tudd, hogy valóban létrejött-e a felhasználó, a home könyvtár és a megfelelő beállítások.

A nano uj_felhasznalo.sh parancs egy új szövegfájlt nyit meg szerkesztésre. Ebbe kerül maga a Bash script.

A chmod +x uj_felhasznalo.sh parancs futtathatóvá teszi a fájlt. A chmod a jogosultságokat módosítja. A +x azt jelenti, hogy a fájl megkapja a végrehajtási jogot. Enélkül a rendszer nem programként, hanem sima fájlként kezelné.

A sudo ./uj_felhasznalo.sh parancs rendszergazdai jogosultsággal indítja el a scriptet. A sudo azért kell, mert felhasználó- és csoportlétrehozás csak megfelelő jogosultsággal végezhető. A ./ azt jelenti, hogy az aktuális könyvtárban lévő fájlt szeretnéd futtatni.

Az id felhasznalo01 parancs megmutatja, hogy létezik-e a felhasználó, és milyen azonosítókat kapott.

Az ls -ld /home/felhasznalo01 parancs kiírja a home könyvtár jogosultságait és tulajdonosi adatait.

A grep felhasznalo01 /etc/passwd parancs megkeresi a felhasználó bejegyzését a rendszer felhasználói nyilvántartásában.

A getent group felhasznalok parancs megmutatja, hogy a felhasznalok csoport létezik-e a rendszerben.

Gyakorlati példa​

A script működése​

A script a következő műveleteket hajtja végre:

  • ellenőrzi, hogy rendszergazda futtatja-e,
  • megad egy alapértelmezett csoportnevet,
  • ellenőrzi, hogy a csoport létezik-e,
  • ha nem létezik, akkor létrehozza,
  • bekéri az új felhasználó nevét,
  • ellenőrzi, hogy ez a név már foglalt-e,
  • létrehozza a felhasználót,
  • beállítja, hogy a felhasználó a megadott csoportba tartozzon,
  • elkészíti a home könyvtárat,
  • beállítja a Bash shellt,
  • jelszót kér az új felhasználóhoz,
  • beállítja a home könyvtár jogosultságait.

Amikor a script elindul, először megnézi, hogy root futtatja-e. Ha nem, akkor azonnal leáll. Ezután beállítja, hogy az új felhasználók közös csoportja felhasznalok legyen. Megvizsgálja, hogy ez a csoport létezik-e, és ha nem, létrehozza. Ezután bekéri a felhasználó nevét. Ha a mező üres, hibával megáll. Ha a név már foglalt, szintén megáll. Ha minden rendben van, létrehozza az új felhasználót, beállítja a csoportját, elkészíti a home könyvtárát, jelszót kér hozzá, majd beállítja a home könyvtár tulajdonosát és jogosultságait. Végül visszajelzést ad a sikeres létrehozásról.

Példafuttatás​

Add meg az új felhasználó nevét: felhasznalo01
Adj meg jelszót az új felhasználónak:
A felhasználó sikeresen létrejött.
Felhasználónév: felhasznalo01
Csoport: felhasznalok
Home könyvtár: /home/felhasznalo01
Shell: /bin/bash

Példa kód​

#!/bin/bash

# Ellenőrzés: csak root futtathatja
if [ "$EUID" -ne 0 ]; then
    echo "Hiba: ezt a scriptet csak root felhasználó futtathatja."
    exit 1
fi

# Alapértelmezett csoport neve
csoport="felhasznalok"

# Csoport ellenőrzése, létrehozása ha nem létezik
if ! getent group "$csoport" &>/dev/null; then
    groupadd "$csoport"
fi

# Felhasználónév bekérése
read -p "Add meg az új felhasználó nevét: " felhasznalonev

# Üres név ellenőrzése
if [ -z "$felhasznalonev" ]; then
    echo "Hiba: a felhasználónév nem lehet üres."
    exit 1
fi

# Ellenőrzés: létezik-e már ilyen felhasználó
if id "$felhasznalonev" &>/dev/null; then
    echo "Hiba: a(z) $felhasznalonev nevű felhasználó már létezik."
    exit 1
fi

# Felhasználó létrehozása home könyvtárral, Bash shell-lel és megadott csoporttal
useradd -m -s /bin/bash -g "$csoport" "$felhasznalonev"

# Sikeresség ellenőrzése
if [ $? -ne 0 ]; then
    echo "Hiba történt a felhasználó létrehozása közben."
    exit 1
fi

# Jelszó beállítása
echo "Adj meg jelszót az új felhasználónak:"
passwd "$felhasznalonev"

# Home könyvtár tulajdonosának és jogosultságainak beállítása
chown -R "$felhasznalonev:$csoport" "/home/$felhasznalonev"
chmod 700 "/home/$felhasznalonev"

# Visszajelzés
echo "A felhasználó sikeresen létrejött."
echo "Felhasználónév: $felhasznalonev"
echo "Csoport: $csoport"
echo "Home könyvtár: /home/$felhasznalonev"
echo "Shell: /bin/bash"

Példakód magyarázat​

1. A Bash értelmező megadása​

#!/bin/bash
Ez a sor megmondja a rendszernek, hogy ezt a fájlt a Bash parancsértelmezővel kell végrehajtani.

Ez a sor a script legelső sora, és gyakran shebang sornak nevezik.

A #! két karakterből áll.

Az első karakter a #, amelyet a scriptben általában megjegyzésekhez is használunk, de a fájl első sorában a ! jellel együtt különleges jelentése van.

A második karakter a !, amely a # után azt jelzi, hogy a rendszer itt nem egyszerű megjegyzést lát, hanem azt az információt, hogy melyik programmal kell értelmezni a scriptet.

A /bin/bash egy elérési út. Ez azt mutatja meg, hogy a Bash értelmező a rendszerben hol található. A /bin könyvtárban vannak az alapvető végrehajtható programok, a bash pedig maga a Bash shell.

Ha ez a sor hiányzik, a script gyakran akkor is lefuthat, ha például kézzel így indítod: bash fajlnev.sh, de önálló futtatásnál a rendszer nem feltétlenül fogja tudni, hogy melyik értelmezőt használja.

Ezért ez a sor majdnem minden Bash script elején ott szokott lenni.

2. Root jogosultság ellenőrzése​

# Ellenőrzés: csak root futtathatja
if [ "$EUID" -ne 0 ]; then
    echo "Hiba: ezt a scriptet csak root felhasználó futtathatja."
    exit 1
fi
Ez a rész azt ellenőrzi, hogy a scriptet valóban rendszergazda futtatja-e, mert felhasználót és csoportot létrehozni csak megfelelő jogosultsággal lehet.

A # Ellenőrzés: csak root futtathatja sor megjegyzés. A # jellel kezdődő sorokat a Bash nem hajtja végre. Ezek az emberi olvasót segítik a program szerkezetének megértésében.

Az if egy feltételes szerkezet kezdete. Azt jelenti, hogy ha valami igaz, akkor végre kell hajtani a belső utasításokat.

A [ ... ] rész a Bash egyik klasszikus feltételvizsgáló formája. Itt maga az ellenőrzés történik. Fontos, hogy a szögletes zárójelek körül szóköz legyen, mert ezek itt különálló elemek.

A "$EUID" egy speciális változó. Az EUID az aktuális felhasználó effective user ID azonosítóját tartalmazza. Ez egy szám. A root felhasználó azonosítója Linuxon általában 0.

A -ne jelentése: not equal, vagyis nem egyenlő.

A 0 a root felhasználót jelenti. Ha az aktuális azonosító nem 0, akkor nem root futtatja a scriptet.

A then szó azt jelenti, hogy ha a feltétel igaznak bizonyul, akkor most jönnek a végrehajtandó utasítások.

Az echo egy kiíró parancs. A feladata, hogy szöveget jelenítsen meg a képernyőn.

Az exit 1 azonnal leállítja a scriptet. Az exit után írt szám a kilépési kód. A 0 sikeres lefutást, a nem 0 érték hibát jelent. Az 1 itt hibás leállás.

A fi az if blokk lezárása.

Ez az egész blokk tehát együtt azt mondja: ha nem root futtatja a scriptet, írj ki hibát, majd állj le.

3. Az alapértelmezett csoport megadása​

# Alapértelmezett csoport neve
csoport="felhasznalok"
Ez a rész létrehoz egy változót, amelyben eltároljuk, hogy az új felhasználók melyik közös csoportba kerüljenek.

A csoport itt egy általunk választott változónév.

Az = jel értékadást jelent. A Bash-ben változó létrehozásakor nem szabad szóközt tenni a változónév, az egyenlőségjel és az érték közé. Tehát jó: csoport="felhasznalok", de hibás lenne például így: csoport = "felhasznalok".

A "felhasznalok" egy karakterlánc, vagyis szöveg.

Ez a sor azt jelenti, hogy a csoport nevű változó értéke felhasznalok lesz.

Ez azért hasznos, mert később nem kell mindenhol újra és újra kiírni a csoport nevét. Elég a változót használni. Ha később más csoportnevet szeretnél, elég itt egy helyen átírni.

4. A csoport ellenőrzése és szükség esetén létrehozása​

# Csoport ellenőrzése, létrehozása ha nem létezik
if ! getent group "$csoport" &>/dev/null; then
    groupadd "$csoport"
fi
Ez a blokk megvizsgálja, hogy a megadott csoport létezik-e, és ha nem, akkor automatikusan létrehozza.

A getent parancs rendszeradatbázisokból kérdez le adatokat.

A group azt mondja meg, hogy most a csoportadatbázisból akarunk keresni.

A "$csoport" a korábban eltárolt változó értéke, jelen esetben a felhasznalok szöveg.

A getent group "$csoport" tehát azt vizsgálja meg, hogy van-e ilyen nevű csoport a rendszerben.

Az &>/dev/null azt jelenti, hogy a parancs normál kimenetét és hibaüzenetét is eldobjuk. Itt most nem az érdekel minket, hogy mit ír ki a parancs, hanem csak az, hogy sikeres volt-e.

A ! logikai negációt jelent. Ez megfordítja a feltétel értékét.

Ha a getent találja a csoportot, akkor a parancs sikeres lesz. A ! miatt ez hamisnak számít, tehát a blokk nem fut le.

Ha a getent nem találja a csoportot, akkor a parancs hibával tér vissza. A ! miatt ez igaznak számít, tehát a blokk lefut.

A then után tehát csak akkor fut le a belső rész, ha a csoport még nem létezik.

A groupadd parancs új csoportot hoz létre Linuxon.

A groupadd "$csoport" azt jelenti, hogy hozd létre a felhasznalok nevű csoportot.

A fi lezárja a feltételes blokkot.

Ez a rész azért hasznos, mert a script nem feltételezi vakon, hogy a kívánt csoport már létezik, hanem szükség esetén maga elkészíti.

5. A felhasználónév bekérése​

# Felhasználónév bekérése
read -p "Add meg az új felhasználó nevét: " felhasznalonev
Ez a rész bekéri a billentyűzetről az új felhasználó nevét, és eltárolja egy változóba.

A read parancs arra való, hogy a felhasználótól adatot kérjen be futás közben.

A -p kapcsoló azt jelenti, hogy a read parancs egyből ki is írhat egy promptszöveget, vagyis egy rövid üzenetet, amely megmondja, milyen adatot várunk.

Az "Add meg az új felhasználó nevét: " rész a promptszöveg. Ez jelenik meg a képernyőn.

A felhasznalonev a változó neve. Ide kerül az a szöveg, amit a felhasználó begépel.

Ha a felhasználó például azt írja be, hogy felhasznalo01, akkor a script innentől kezdve a felhasznalonev változóban ezt az értéket fogja tárolni.

Ez a sor még nem ellenőrzi, hogy a megadott név helyes-e vagy üres-e. Csak bekéri és eltárolja azt.

6. Az üres érték ellenőrzése​

# Üres név ellenőrzése
if [ -z "$felhasznalonev" ]; then
    echo "Hiba: a felhasználónév nem lehet üres."
    exit 1
fi
Ez a rész megakadályozza, hogy a script üres felhasználónévvel próbáljon tovább dolgozni.

Az if itt is feltételvizsgálatot indít.

A [ -z "$felhasznalonev" ] kifejezés azt nézi meg, hogy a változó üres-e.

A -z egy speciális tesztoperátor. A jelentése az, hogy az utána megadott karakterlánc hossza nulla-e. Magyarul: nincs benne semmi.

A "$felhasznalonev" a korábban bekért adat. Ha a felhasználó csak entert nyomott, és nem írt be semmit, akkor ez a változó üres lesz.

A then itt is azt jelzi, hogy ha a feltétel igaz, akkor végre kell hajtani a belső utasításokat.

Az echo "Hiba: a felhasználónév nem lehet üres." kiír egy egyértelmű hibaüzenetet.

Az exit 1 leállítja a scriptet hibával.

A fi lezárja a feltételes blokkot.

Erre az ellenőrzésre azért van szükség, mert üres névből nem lehet valódi Linux felhasználót készíteni. Ha ezt nem vizsgálnánk, a későbbi parancsok hibát adnának.

7. Annak ellenőrzése, hogy a felhasználó már létezik-e​

# Ellenőrzés: létezik-e már ilyen felhasználó
if id "$felhasznalonev" &>/dev/null; then
    echo "Hiba: a(z) $felhasznalonev nevű felhasználó már létezik."
    exit 1
fi
Ez a blokk megvizsgálja, hogy a megadott név szerepel-e már a rendszer felhasználói között.

Az id parancs Linuxon megmutatja egy felhasználó azonosítóit és csoportjait. Ha a megadott felhasználó létezik, akkor az id sikeresen lefut. Ha nem létezik, akkor hibával tér vissza.

Az id "$felhasznalonev" tehát azt próbálja meg, hogy lekérdezze a bekért nevű felhasználót.

A &>/dev/null azt jelenti, hogy a parancs normál kimenetét és hibaüzenetét is eldobjuk.

Ez azért kell, mert itt nem az érdekel minket, hogy mit ír ki az id, hanem csak az, hogy sikeres volt-e a futása.

A then rész akkor hajtódik végre, ha az id parancs sikeres volt. Ez azt jelenti, hogy a felhasználó már létezik.

Az echo kiírja a hibaüzenetet.

Az exit 1 itt is azonnali hibás leállást jelent.

A fi lezárja a blokkot.

Ez a rész nagyon fontos, mert Linuxon ugyanazzal a névvel nem lehet még egyszer létrehozni ugyanazt a felhasználót.

8. A felhasználó létrehozása​

# Felhasználó létrehozása home könyvtárral, Bash shell-lel és megadott csoporttal
useradd -m -s /bin/bash -g "$csoport" "$felhasznalonev"
Ez a sor hozza létre ténylegesen az új Linux felhasználót a megadott beállításokkal.

A useradd egy rendszergazdai parancs, amely új felhasználót hoz létre a rendszerben.

A -m kapcsoló azt mondja a parancsnak, hogy a felhasználóhoz automatikusan készítse el a home könyvtárat is. Ez rendszerint a /home/felhasznalonev mappa lesz.

A -s /bin/bash kapcsolóval megadjuk az alapértelmezett shellt.

A -s azt jelenti, hogy shell.

A /bin/bash itt azt mondja meg, hogy az adott felhasználó belépéskor a Bash parancsértelmezőt kapja.

A -g "$csoport" kapcsoló az elsődleges csoportot állítja be.

A -g jelentése itt: a felhasználó elsődleges csoportja legyen a megadott csoport.

A "$csoport" jelenleg a felhasznalok értéket tartalmazza.

A "$felhasznalonev" a létrehozandó felhasználó neve.

Ez a sor tehát együtt azt jelenti: hozz létre egy új felhasználót a megadott névvel, készíts neki home könyvtárat, állítsd be neki a Bash shellt, és tedd a megadott csoportba.

9. A useradd parancs sikerességének ellenőrzése​

# Sikeresség ellenőrzése
if [ $? -ne 0 ]; then
    echo "Hiba történt a felhasználó létrehozása közben."
    exit 1
fi
Ez a rész azt ellenőrzi, hogy az előző parancs valóban sikeresen lefutott-e.

A $? egy nagyon fontos speciális változó Bash-ben. Mindig az előzőleg lefutott parancs kilépési kódját tartalmazza.

Ha egy parancs sikeresen lefutott, akkor általában 0 az értéke.

Ha hiba történt, akkor általában nem 0 az értéke.

A [ $? -ne 0 ] feltétel tehát azt vizsgálja, hogy az előző parancs kilépési kódja nem 0-e.

A -ne jelentése itt is nem egyenlő.

A 0 itt a sikeres végrehajtást jelenti.

A then azt mondja, hogy ha a useradd parancs hibával futott le, akkor hajtsuk végre a belső utasításokat.

Az echo kiír egy általános hibaüzenetet.

Az exit 1 leállítja a scriptet hibával.

A fi lezárja a blokkot.

Ez a rész azért fontos, mert a useradd több ok miatt is hibázhat. Például ha érvénytelen a felhasználónév, ha nincs jogosultság, vagy ha valamilyen rendszerhiba történik.

10. Jelszó beállítása​

# Jelszó beállítása
echo "Adj meg jelszót az új felhasználónak:"
passwd "$felhasznalonev"
Ez a blokk először tájékoztatja a felhasználót, majd interaktívan jelszót állít be az új fiókhoz.

Az echo "Adj meg jelszót az új felhasználónak:" csak egy tájékoztató szöveget ír ki.

A passwd parancs Linuxon jelszó beállítására vagy módosítására szolgál.

A "$felhasznalonev" megadja, hogy melyik felhasználó jelszavát akarjuk beállítani.

Amikor ez a parancs lefut, a rendszer általában kétszer kéri be a jelszót. Az első megadás után még egyszer be kell írni ugyanazt, hogy elkerülhető legyen a gépelési hiba.

Fontos, hogy a jelszó gépelése közben általában nem jelennek meg karakterek a képernyőn. Ez normális Linux viselkedés.

Ez a rész interaktív, tehát a script itt várni fog a felhasználói bevitelre.

11. A home könyvtár tulajdonosának beállítása​

# Home könyvtár tulajdonosának és jogosultságainak beállítása
chown -R "$felhasznalonev:$csoport" "/home/$felhasznalonev"
Ez a sor gondoskodik arról, hogy a home könyvtár tulajdonosa az új felhasználó legyen, a csoportja pedig a megadott csoport maradjon.

A chown parancs neve a "change owner" rövidítése. Tulajdonost és csoportot lehet vele módosítani.

A -R kapcsoló jelentése: rekurzív. Ez azt jelenti, hogy ne csak magára a könyvtárra vonatkozzon a művelet, hanem minden benne található fájlra és almappára is.

A "$felhasznalonev:$csoport" rész két adatot ad meg.

Az első a tulajdonos neve.

A kettőspont utáni rész a csoport neve.

A "/home/$felhasznalonev" a home könyvtár elérési útja.

Ez a sor tehát azt állítja be, hogy a home könyvtár tulajdonosa maga a felhasználó legyen, de a csoport-hozzárendelés a megadott csoport maradjon.

12. A home könyvtár jogosultságának beállítása​

chmod 700 "/home/$felhasznalonev"
Ez a sor beállítja, hogy a home könyvtárhoz csak maga a felhasználó férhessen hozzá.

A chmod parancs neve a "change mode" rövidítése. Jogosultságokat lehet vele beállítani.

A 700 egy számos jogosultsági forma.

Ez három számjegyből áll.

Az első számjegy a tulajdonos jogait adja meg.

A második a csoport jogait.

A harmadik minden más felhasználó jogait.

A 7 jelentése: olvasás, írás és belépés.

A 0 jelentése: nincs jogosultság.

Tehát a 700 jelentése itt az, hogy:

a tulajdonos beléphet, listázhat, módosíthat,

a csoport nem fér hozzá,

mások sem férnek hozzá.

Ez azért fontos, mert a saját home könyvtár alapértelmezetten privát terület kell legyen.

13. Visszajelzés a script végén​

# Visszajelzés
echo "A felhasználó sikeresen létrejött."
echo "Felhasználónév: $felhasznalonev"
echo "Csoport: $csoport"
echo "Home könyvtár: /home/$felhasznalonev"
echo "Shell: /bin/bash"
Ez a blokk összefoglalja a sikeres futás eredményét, hogy a rendszergazda rögtön lássa, mi jött létre.

Az első echo egy általános sikerüzenet.

A második kiírja a létrehozott felhasználó nevét.

A harmadik kiírja, hogy a felhasználó melyik csoportba került.

A negyedik kiírja a home könyvtár elérési útját.

Az ötödik kiírja a beállított shellt.

Ez a blokk nem kötelező a működéshez, de adminisztrációs és oktatási szempontból nagyon hasznos, mert azonnali visszajelzést ad.

Gyakorlati feladat​

Készíts egy uj_fiok.sh nevű Bash scriptet, amely egy új felhasználót hoz létre.

A script feladata legyen:

  1. Ellenőrizze, hogy root futtatja-e.
  2. Hozzon létre egy munkatarsak nevű csoportot, ha még nem létezik.
  3. Kérje be az új felhasználó nevét.
  4. Vizsgálja meg, hogy a név foglalt-e.
  5. Hozza létre a felhasználót home könyvtárral.
  6. Állítsa be a /bin/bash shellt.
  7. Tegye a munkatarsak csoportba.
  8. Kérjen jelszót.
  9. Állítsa be a home könyvtár jogosultságát 700 értékre.
  10. A végén írja ki a létrehozott felhasználó nevét, csoportját és home könyvtárát.

Plusz feladat (szorgalmi)​

Egészítsd ki a scriptedet úgy, hogy a végén a következőket is kiírja:

  • az új felhasználó UID azonosítóját,
  • az elsődleges csoport nevét,
  • azt, hogy létezik-e a home könyvtár,
  • és azt is, hogy a megadott csoport hány tagot tartalmaz.
Feladatmegoldás
#!/bin/bash

if [ "$EUID" -ne 0 ]; then
    echo "Hiba: ezt a scriptet csak root felhasználó futtathatja."
    exit 1
fi

csoport="munkatarsak"

if ! getent group "$csoport" &>/dev/null; then
    groupadd "$csoport"
fi

read -p "Add meg az új felhasználó nevét: " felhasznalonev

if [ -z "$felhasznalonev" ]; then
    echo "Hiba: a felhasználónév nem lehet üres."
    exit 1
fi

if id "$felhasznalonev" &>/dev/null; then
    echo "Hiba: a(z) $felhasznalonev nevű felhasználó már létezik."
    exit 1
fi

useradd -m -s /bin/bash -g "$csoport" "$felhasznalonev"

if [ $? -ne 0 ]; then
    echo "Hiba történt a felhasználó létrehozása közben."
    exit 1
fi

echo "Adj meg jelszót az új felhasználónak:"
passwd "$felhasznalonev"

chown -R "$felhasznalonev:$csoport" "/home/$felhasznalonev"
chmod 700 "/home/$felhasznalonev"

echo "A felhasználó sikeresen létrejött."
echo "Felhasználónév: $felhasznalonev"
echo "Csoport: $csoport"
echo "Home könyvtár: /home/$felhasznalonev"
echo "Shell: /bin/bash"

Reset script a példa teljes visszaállításához

Ez a script arra való, hogy a példában létrehozott felhasználókat, home könyvtárakat és csoportot eltávolítsd, majd tiszta állapotból újra tudd kezdeni a gyakorlást.

A script elején a változókat szabadon átírhatod. Így ugyanaz a reset script több különböző példánál is használható.

#!/bin/bash

if [ "$EUID" -ne 0 ]; then
    echo "Hiba: ezt a scriptet csak root felhasználó futtathatja."
    exit 1
fi

# Testreszabható adatok
csoport="felhasznalok"
felhasznalok=("felhasznalo01" "felhasznalo02")

echo "Törlés indul..."

# Felhasználók törlése home könyvtárral együtt
for felhasznalonev in "${felhasznalok[@]}"; do
    if id "$felhasznalonev" &>/dev/null; then
        userdel -r "$felhasznalonev"
        echo "Törölve: $felhasznalonev"
    else
        echo "Nem létezik, kihagyva: $felhasznalonev"
    fi
done

# Csoport törlése, ha létezik
if getent group "$csoport" &>/dev/null; then
    groupdel "$csoport"
    if [ $? -eq 0 ]; then
        echo "Törölve a csoport: $csoport"
    else
        echo "A csoport nem törölhető. Lehet, hogy még tartozik hozzá felhasználó."
    fi
else
    echo "A csoport nem létezik: $csoport"
fi

echo "A reset művelet befejeződött."

Ha csak egyetlen felhasználót akarsz törölni, akkor a tömbben elég egy nevet meghagyni:

felhasznalok=("felhasznalo01")

Ha másik csoportot használtál a példában, akkor ezt a sort kell átírnod:

csoport="munkatarsak"

A userdel -r parancs törli a felhasználót, és megpróbálja eltávolítani a home könyvtárát is.

A groupdel parancs törli a csoportot, de csak akkor, ha nincs olyan állapot, ami ezt megakadályozza.
