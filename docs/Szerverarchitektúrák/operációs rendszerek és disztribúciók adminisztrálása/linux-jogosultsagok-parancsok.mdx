# Linux Jogosultságok - Parancscsomag

<details>
<summary>0. Csoportok és felhasználók létrehozása</summary>

```bash
# CSOPORTOK
groupadd management
groupadd sales
groupadd accounting
groupadd students

# FELHASZNÁLÓK (home mappával, alap csoporttal, bash shell-lel)
useradd -m -g management  -s /bin/bash boss1
useradd -m -g sales       -s /bin/bash sales1
useradd -m -g sales       -s /bin/bash sales2
useradd -m -g accounting  -s /bin/bash acc1
useradd -m -g accounting  -s /bin/bash acc2
useradd -m -g students    -s /bin/bash student1
useradd -m -g students    -s /bin/bash student2

# JELSZÓK BEÁLLÍTÁSA
passwd boss1
passwd sales1
passwd sales2
passwd acc1
passwd acc2
passwd student1
passwd student2
```

**Ellenőrzés:**
```bash
getent group management sales accounting students
id boss1
id sales1
id acc1
id student1
```

</details>

<details>
<summary>1. Könyvtárstruktúra létrehozása</summary>

```bash
mkdir -p /srv/compani/{management_mappa,sales_mappa,accounting_mappa,shared_mappa}
```

**Ellenőrzés:**
```bash
tree -d /srv/compani 2>/dev/null || find /srv/compani -maxdepth 1 -type d -print
```

</details>

<details>
<summary>2. Jogosultságok beállítása - Sales mappa</summary>

```bash
chown root:sales /srv/compani/sales_mappa
chmod 2770 /srv/compani/sales_mappa

# management kapjon teljes hozzáférést
setfacl -m g:management:rwx /srv/compani/sales_mappa
# alapértelmezett öröklés (új fájlokra/mappákra)
setfacl -d -m g:management:rwx /srv/compani/sales_mappa
```

**Ellenőrzés:**
```bash
ls -ld /srv/compani/sales_mappa
getfacl /srv/compani/sales_mappa | sed -n '1,25p'
```

</details>

<details>
<summary>5. Jogosultságok beállítása - Shared mappa</summary>

```bash
chown root:students /srv/compani/shared_mappa
chmod 2770 /srv/compani/shared_mappa

# sales + accounting + management kapjon hozzáférést
setfacl -m g:sales:rwx /srv/compani/shared_mappa
setfacl -m g:accounting:rwx /srv/compani/shared_mappa
setfacl -m g:management:rwx /srv/compani/shared_mappa

# öröklés (új fájlokra/mappákra)
setfacl -d -m g:sales:rwx /srv/compani/shared_mappa
setfacl -d -m g:accounting:rwx /srv/compani/shared_mappa
setfacl -d -m g:management:rwx /srv/compani/shared_mappa
```

**Ellenőrzés:**
```bash
getfacl /srv/compani/shared_mappa | sed -n '1,40p'
```

</details>

<details>
<summary>6. Tesztelés - Sales felhasználó</summary>

```bash
su - sales1

# SALES: saját mappába írhat
touch /srv/compani/sales_mappa/sales1_ok.txt

# ACCOUNTING: ne férjen hozzá (hibát kell dobjon)
touch /srv/compani/accounting_mappa/sales1_should_fail.txt

# SHARED: férjen hozzá
touch /srv/compani/shared_mappa/sales1_shared_ok.txt

exit
```

</details>

<details>
<summary>10. Hibaelhárítás - Permission denied esetén</summary>
