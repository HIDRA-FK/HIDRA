# Fejlesztői környezet kialakítása

Ebben a fejezetben a gyakorlati feladatok elvégzéséhez szükséges fejlesztői környezetet készítjük elő.  
A további tananyag minden része erre a környezetre épül, ezért a fejezet lépéseinek pontos végrehajtása alapfeltétel.

A fejezet célja annak bemutatása, hogyan lehet:
- Windows alatt parancssori munkakörnyezetet használni,
- virtuális környezetben Linux szervert telepíteni,
- valamint kliensoldalról csatlakozni a szerverhez.

A fejezet végére rendelkezünk egy működő Ubuntu Serverrel és egy olyan klienskörnyezettel, amelyből a későbbi gyakorlatok végrehajthatók.

---

## Parancssori munkakörnyezet Windows alatt

Windows operációs rendszeren ehhez egy külső terminálprogramot használunk, amely alkalmas Linux parancsok futtatására és SSH-kapcsolatok kezelésére.

## Linux szerver telepítése virtuális környezetben

A gyakorlati feladatokat nem éles szerveren, hanem egy elkülönített virtuális környezetben végezzük.  
Ehhez virtualizációs szoftvert használunk, amely lehetővé teszi egy Linux szerver futtatását a meglévő operációs rendszer mellett.

A Linux szerver kezelése grafikus felület nélkül, távoli parancssoros kapcsolaton keresztül történik.  
Ehhez a kliensoldali gépről SSH-kapcsolatot hozunk létre a szerverrel.
