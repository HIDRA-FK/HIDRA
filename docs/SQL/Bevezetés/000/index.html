Bevezetés az SQL világába

A mindennapi életben nagyon sok olyan rendszerrel találkozunk, amely nagy mennyiségű adatot tárol és kezel. Ilyen például egy iskolai nyilvántartás, egy webáruház terméklistája, egy könyvtári rendszer vagy akár egy bank ügyféladatbázisa is. Ezekben a rendszerekben az adatokat rendezett, jól átlátható formában kell tárolni, hogy később gyorsan vissza lehessen keresni, módosítani vagy bővíteni őket.

Ebben a tananyagban az adatbázisok alapjaival és az SQL nyelv első elemeivel foglalkozunk. A cél az, hogy megértsd, mit jelent az adatbázis fogalma, hogyan épül fel egy tábla, és hogyan lehet egy táblából adatokat lekérdezni.

Az adatbázis fogalma​

Az adatbázis olyan strukturált adattárolási forma, amelyben az információkat rendezett módon tároljuk. Az adatbázis célja, hogy az adatokat könnyen és hatékonyan lehessen kezelni.

Az adatbázis használatával lehetőség van:

  • adatok rögzítésére,
  • adatok keresésére,
  • adatok módosítására,
  • adatok törlésére.

Minél több adatot kell kezelni, annál fontosabb, hogy ezek ne rendezetlenül, hanem jól szervezett rendszerben legyenek eltárolva.

Az adatbázis alapfogalmai​

Az adatbázis egyik legfontosabb eleme a tábla. A tábla sorokból és oszlopokból áll, hasonlóan egy táblázathoz.

Egy tábla például tartalmazhatja egy iskola tanulóinak adatait. Ebben az esetben a táblában szerepelhet a tanuló neve, életkora, osztálya és átlaga.

A táblában található vízszintes egységeket soroknak nevezzük. Egy sor általában egyetlen rekordot jelent, vagyis egy konkrét személyhez, termékhez vagy eseményhez tartozó összes adatot.

A függőleges egységeket oszlopoknak nevezzük. Az oszlopok egy-egy tulajdonságot jelentenek, például nevet, életkort vagy osztályt.

A sor és oszlop metszetében található egy konkrét adat, ezt mezőnek nevezzük.

Az alábbi példa egy egyszerű tanulok nevű táblát mutat:

idnevosztalyatlag
1Kiss Anna10.A4.7
2Nagy Péter10.B3.9

A példában:

  • a nev egy oszlop,
  • az első sor egy tanuló teljes adatait tartalmazza,
  • a Kiss Anna érték egy mező.

Az SQL szerepe​

Az SQL a Structured Query Language rövidítése. Ez egy olyan nyelv, amelyet relációs adatbázisok kezelésére használunk.

Az SQL segítségével lehet:

  • adatokat lekérdezni,
  • új adatokat rögzíteni,
  • meglévő adatokat módosítani,
  • adatokat törölni.

Ebben az első anyagban csak a lekérdezések alapjaival foglalkozunk.

A SELECT utasítás​

Az SQL egyik legalapvetőbb utasítása a SELECT. Ezt akkor használjuk, amikor adatokat szeretnénk lekérdezni egy táblából.

A SELECT utasítással megadjuk, hogy mely adatokat szeretnénk látni, a FROM kulcsszóval pedig azt, hogy melyik táblából kérjük le azokat.

Az alábbi példa megmutatja egy egyszerű lekérdezés szerkezetét:

SELECT * FROM tanulok;

A lekérdezés jelentése:

  • SELECT – adatok lekérdezése,
  • * – az összes oszlop lekérdezése,
  • FROM tanulok – a tanulok nevű táblából.

Ez a lekérdezés tehát a tanulok tábla minden adatát megjeleníti.

Egyszerű lekérdezések​

Ha a tábla minden oszlopát szeretnéd megjeleníteni, akkor használhatod a következő lekérdezést:

SELECT * FROM tanulok;

Ha csak a tanulók nevét szeretnéd látni, akkor elegendő az adott oszlop nevét megadni:

SELECT nev FROM tanulok;

Ha egyszerre több oszlopot szeretnél lekérdezni, akkor az oszlopneveket vesszővel kell elválasztani:

SELECT nev, osztaly FROM tanulok;

Az alábbi példa a tanulók nevét és átlagát jeleníti meg:

SELECT nev, atlag FROM tanulok;

A FROM szerepe​

A FROM kulcsszó minden lekérdezésben azt jelöli, hogy melyik táblából szeretnénk adatot kérni.

Például:

SELECT nev FROM tanulok;

Ebben a lekérdezésben a nev oszlop adatait a tanulok nevű táblából kérjük le.

Ha a tábla nevét hibásan írjuk le, akkor a lekérdezés nem fog működni, mert az adatbázis nem talál ilyen nevű táblát.

Miért nem célszerű mindig a * használata?​

A tanulás elején a SELECT * hasznos, mert egyszerű és gyors megoldás. Később azonban célszerű csak azokat az oszlopokat lekérdezni, amelyekre valóban szükség van.

Például az alábbi lekérdezés:

SELECT nev, atlag FROM tanulok;

átláthatóbb, mint ez:

SELECT * FROM tanulok;

Ez különösen akkor fontos, ha a tábla sok oszlopot tartalmaz.

Minta a lekérdezések értelmezéséhez​

Tegyük fel, hogy a tanulok tábla a következő adatokat tartalmazza:

idneveletkorosztalyatlag
1Kiss Anna1610.A4.7
2Nagy Péter1710.B3.9
3Tóth Réka1610.A4.4

A következő lekérdezés a teljes táblát jeleníti meg:

SELECT * FROM tanulok;

A következő csak a neveket listázza:

SELECT nev FROM tanulok;

A következő a neveket és az osztályokat írja ki:

SELECT nev, osztaly FROM tanulok;

A következő pedig a neveket és az átlagokat jeleníti meg:

SELECT nev, atlag FROM tanulok;

CREATE DATABASE IF NOT EXISTS iskola;
USE iskola;

DROP TABLE IF EXISTS tanulok;

CREATE TABLE tanulok (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nev VARCHAR(100) NOT NULL,
    eletkor INT NOT NULL,
    osztaly VARCHAR(10) NOT NULL,
    atlag DECIMAL(3,1) NOT NULL
);
