# Automatizáció PowerShell segítségével

Ez a fejezet a PowerShell automatizálási célú használatát vezeti be. A témakör középpontjában azok a feladatok állnak, amelyeket nem egyszeri kézi parancsfuttatással, hanem scriptbe szervezett, ismételhető műveletsorral érdemes megoldani.

Az automatizáció célja, hogy egy feladat végrehajtása következetesebb, gyorsabban ismételhető és könnyebben ellenőrizhető legyen. PowerShellben ez scriptfájlokkal, paraméterezéssel, feltételekkel, ciklusokkal, fájlkezeléssel és naplózással valósítható meg.

:::info Hamarosan
A fejezet anyagai fokozatosan kerülnek feltöltésre.  
A későbbi leckékben konkrét automatizálási feladatok PowerShell-alapú megoldása szerepel majd.
:::

## Várható témakörök

A fejezetben többek között az alábbi területek jelennek meg:

```text
scriptfájlok felépítése
paraméterezhető scriptek készítése
ismétlődő feladatok automatizálása
mappák és fájlok tömeges kezelése
adatok beolvasása fájlból
eredmények mentése fájlba
naplózás
hibakezelés alapjai
ellenőrzések beépítése scriptbe
feltételes végrehajtás automatizációban
ütemezett futtatás alapjai
karbantartási feladatok automatizálása
````

## Scriptfájlok szerepe

Az automatizáció alapja a scriptfájl. PowerShellben a scriptfájl kiterjesztése:

```text
.ps1
```

A scriptfájl több parancsot tartalmazhat egymás után, így egy teljes műveletsor egyetlen fájlból futtatható.

Példák automatizálható műveletsorokra:

```text
mappaszerkezet létrehozása
fájlok átmásolása adott helyre
régi fájlok törlése
naplófájlok összegyűjtése
rendszerállapot lekérdezése
eredmények mentése szövegfájlba
```

A script célja nem az, hogy egyetlen parancsot helyettesítsen, hanem az, hogy több egymáshoz kapcsolódó műveletet egységes, újrafuttatható formába szervezzen.

## Paraméterezhető működés

Egy automatizált script akkor használható rugalmasan, ha nem minden érték van közvetlenül beégetve a kódba.

A későbbi leckékben szó lesz arról, hogyan lehet egy scriptet paraméterezhetővé tenni, például:

```text
melyik mappán dolgozzon
milyen fájltípust keressen
hány napnál régebbi fájlokat kezeljen
hová mentse az eredményt
kell-e naplózást készítenie
```

Példa szemlélet:

```powershell
param(
    [string]$ForrasMappa,
    [string]$CelMappa
)
```

Ez lehetővé teszi, hogy ugyanaz a script több különböző helyzetben is használható legyen.

## Ismétlődő feladatok automatizálása

Automatizációra főleg akkor van szükség, ha egy műveletet rendszeresen, azonos logika szerint kell végrehajtani.

Ilyen feladat lehet például:

```text
minden naplófájl összegyűjtése
régi ideiglenes fájlok törlése
mentési mappa létrehozása dátum alapján
felhasználói lista feldolgozása
mappák jogosultságainak ellenőrzése
szolgáltatások állapotának naplózása
```

A PowerShell ezeknél a feladatoknál nemcsak a végrehajtást gyorsítja, hanem csökkenti annak esélyét is, hogy egy lépés kimaradjon vagy eltérően történjen meg.

## Tömeges fájl- és mappakezelés

Az automatizáció egyik gyakori területe a fájlok és mappák tömeges kezelése.

A fejezet későbbi részeiben szerepelhet például:

```text
adott kiterjesztésű fájlok keresése
fájlok áthelyezése szabály alapján
régi fájlok törlése
mappák létrehozása lista alapján
fájlnevek módosítása
fájlméretek ellenőrzése
eredmények exportálása
```

Ezeknél a feladatoknál a `Get-ChildItem`, `Where-Object`, `Copy-Item`, `Move-Item`, `Remove-Item`, `Set-Content` és `Add-Content` parancsok gyakran együtt jelennek meg.

## Adatok beolvasása és feldolgozása

Egy automatizált script gyakran külső adatok alapján dolgozik. Ezek az adatok érkezhetnek például szövegfájlból, CSV-állományból vagy felhasználói bemenetből.

Várható témák:

```text
sorok beolvasása szövegfájlból
CSV-fájl feldolgozása
adatok szűrése
adatok ellenőrzése
hibás rekordok elkülönítése
eredmények mentése
```

Példa:

```powershell
$nevek = Get-Content -Path .\nevek.txt
```

A beolvasott adatok ezután ciklussal, feltételekkel és szűréssel feldolgozhatók.

## Naplózás

Automatizált műveleteknél fontos, hogy a script futása később is ellenőrizhető legyen. Erre szolgál a naplózás.

A naplózás során a script rögzítheti például:

```text
mikor indult el
milyen műveleteket hajtott végre
milyen fájlokat érintett
történt-e hiba
mikor fejeződött be
```

Egyszerű naplózási példa:

```powershell
Add-Content -Path .\naplo.txt -Value "A script elindult."
```

Később a naplózás kiegészíthető dátummal, időponttal, hibákkal és részletesebb műveleti üzenetekkel.

## Hibakezelés és ellenőrzés

Automatizációban különösen fontos, hogy a script ne csak végrehajtson parancsokat, hanem ellenőrizze is a feltételeket.

Példák ellenőrzésekre:

```text
létezik-e a forrásmappa
létezik-e a célmappa
van-e feldolgozható fájl
érvényes-e a megadott bemenet
sikerült-e a művelet
kell-e hibát naplózni
```

Példa:

```powershell
if (Test-Path -Path .\adatok.txt) {
    Get-Content -Path .\adatok.txt
}
else {
    Write-Host "A fájl nem található."
}
```

A későbbi leckékben előkerülhet a `try`, `catch`, `finally` szerkezet is, amely összetettebb hibakezelésre használható.

## Ütemezett futtatás

Az automatizáció akkor válik rendszeres működéssé, ha a script nemcsak kézzel, hanem időzítve is futtatható.

A fejezet későbbi részeiben szó lehet például:

```text
script futtatása adott időpontban
napi vagy heti karbantartási feladatok
Windows Feladatütemező használata
naplózott automatikus futtatás
ismétlődő ellenőrző scriptek
```

Az ütemezett futtatás különösen hasznos karbantartási, mentési, törlési és ellenőrzési feladatoknál.
