PowerShell – Logikai operátorok

Alap logikai értékek​

PowerShellben a logikai értékek:

$true
$false

A $true igaz értéket, a $false hamis értéket jelent.

Példa:

Write-Host (5 -gt 3)   # True
Write-Host (2 -eq 4)   # False

Az összehasonlítás eredménye logikai érték.

$eredmeny = 5 -gt 3

Write-Host $eredmeny
Write-Host $eredmeny.GetType().Name

Lehetséges eredmény:

True
Boolean

PowerShellben az összehasonlító operátorok nem a matematikában vagy más programozási nyelvekben megszokott jelekkel működnek.

Általános forma     PowerShell
5 > 3               5 -gt 3
5 < 3               5 -lt 3
5 == 3              5 -eq 3
5 != 3              5 -ne 3

Összehasonlító operátorok​

A logikai kifejezésekben gyakran összehasonlítások szerepelnek. Ezek eredménye $true vagy $false.

OperátorJelentésPélda
-eqegyenlő$kor -eq 18
-nenem egyenlő$kor -ne 18
-gtnagyobb$kor -gt 18
-genagyobb vagy egyenlő$kor -ge 18
-ltkisebb$kor -lt 18
-lekisebb vagy egyenlő$kor -le 18

Példa:

$kor = 20

Write-Host ($kor -eq 18)   # False
Write-Host ($kor -ne 18)   # True
Write-Host ($kor -gt 18)   # True
Write-Host ($kor -ge 18)   # True
Write-Host ($kor -lt 18)   # False
Write-Host ($kor -le 18)   # False

A -gt, -ge, -lt és -le operátorok főleg rendezhető értékeknél használhatók, például számoknál és dátumoknál.

Dátum összehasonlítása:

$datum = Get-Date
$hatarido = [datetime]"2026-12-31"

Write-Host ($datum -lt $hatarido)

Logikai operátorok​

A logikai operátorok több logikai kifejezést kapcsolnak össze.

OperátorJelentésPéldaEredmény
-andlogikai ÉS(5 -gt 3) -and (10 -gt 2)True
-orlogikai VAGY(5 -gt 10) -or (3 -gt 1)True
-notlogikai NEM-not (5 -gt 3)False
-xorkizáró VAGY$true -xor $falseTrue

Az -and akkor ad igaz eredményt, ha mindkét feltétel igaz.

Write-Host ((5 -gt 3) -and (10 -gt 2))   # True

Az -or akkor ad igaz eredményt, ha legalább az egyik feltétel igaz.

Write-Host ((5 -gt 10) -or (3 -gt 1))    # True

A -not megfordítja a logikai értéket.

Write-Host (-not (5 -gt 3))              # False

Az -xor akkor ad igaz eredményt, ha pontosan az egyik feltétel igaz.

Write-Host ($true -xor $false)           # True
Write-Host ($true -xor $true)            # False

A -not helyett használható a ! jel is.

Write-Host (!(5 -gt 3))                  # False

Szakmai anyagban a -not alak következetesebb, mert illeszkedik a PowerShell operátorneveihez.

Példák logikai kifejezésekre​

$a = 7
$b = 3

Write-Host ($a -gt 5 -and $b -lt 5)   # True
Write-Host ($a -gt 10 -or $b -lt 5)   # True
Write-Host (-not ($a -gt $b))         # False

Az első kifejezés:

$a -gt 5 -and $b -lt 5

Értelmezése:

$a -gt 5      igaz, mert 7 nagyobb mint 5
$b -lt 5      igaz, mert 3 kisebb mint 5

Az eredmény igaz, mert mindkét feltétel igaz.

A második kifejezés:

$a -gt 10 -or $b -lt 5

Értelmezése:

$a -gt 10     hamis, mert 7 nem nagyobb mint 10
$b -lt 5      igaz, mert 3 kisebb mint 5

Az eredmény igaz, mert legalább az egyik feltétel igaz.

A harmadik kifejezés:

-not ($a -gt $b)

Értelmezése:

$a -gt $b     igaz, mert 7 nagyobb mint 3

A -not megfordítja az igaz értéket, ezért az eredmény hamis.

Igazságtáblák​

-and​

ABA -and B
$true$true$true
$true$false$false
$false$true$false
$false$false$false

-or​

ABA -or B
$true$true$true
$true$false$true
$false$true$true
$false$false$false

-not​

A-not A
$true$false
$false$true

-xor​

ABA -xor B
$true$true$false
$true$false$true
$false$true$true
$false$false$false

A -xor kizáró VAGY. Akkor igaz, ha a két oldal logikai értéke eltér.

Műveletek sorrendje​

A logikai operátorok kiértékelési sorrendje:

1. -not
2. -and
3. -or, -xor

Példa:

$eredmeny = $true -or $false -and (-not $false)

Write-Host $eredmeny

Eredmény:

True

Lépések:

-not $false
eredménye: True
$false -and $true
eredménye: False
$true -or $false
eredménye: True

Zárójelezve:

$eredmeny = $true -or ($false -and (-not $false))

Write-Host $eredmeny

Összetett feltételeknél a zárójelezés nemcsak a műveleti sorrendet teszi egyértelművé, hanem a kód olvashatóságát is javítja.

Logikai kifejezések változókkal​

Logikai érték közvetlenül is tárolható változóban.

$vanJegy = $true
$aktiv = $false

Write-Host $vanJegy
Write-Host $aktiv

Összehasonlítás eredménye is menthető változóba.

$kor = 20
$nagyKoru = $kor -ge 18

Write-Host $nagyKoru

Eredmény:

True

Több feltétel összekapcsolása:

$kor = 20
$vanJegy = $true

$belephet = ($kor -ge 18) -and $vanJegy

Write-Host $belephet

Eredmény:

True

A $vanJegy már önmagában logikai érték, ezért nem szükséges külön így írni:

$vanJegy -eq $true

A rövidebb, közvetlen forma:

$vanJegy

Összehasonlítás és logikai operátor együtt​

A logikai operátorok általában összehasonlítások eredményét kapcsolják össze.

$kor = 20
$vanJegy = $true

Write-Host (($kor -ge 18) -and $vanJegy)

Eredmény:

True

Ebben a példában:

$kor -ge 18     igaz
$vanJegy        igaz

A teljes kifejezés igaz, mert az -and mindkét oldalán igaz érték áll.

Másik példa:

$kor = 16
$szuloiEngedely = $true

$belephet = ($kor -ge 18) -or $szuloiEngedely

Write-Host $belephet

Eredmény:

True

A kifejezés jelentése:

A belépés engedélyezett, ha a felhasználó legalább 18 éves,
vagy rendelkezik szülői engedéllyel.

Rövidzáras kiértékelés​

A PowerShell logikai operátorai rövidzáras kiértékelést alkalmaznak.

-and esetén, ha az első feltétel hamis, a második feltételt már nem szükséges kiértékelni, mert a teljes kifejezés biztosan hamis.

$ertek = 0

($ertek -ne 0) -and ((10 / $ertek) -gt 1)

Ebben a példában a második rész nem kerül kiértékelésre, mert az első feltétel hamis.

-or esetén, ha az első feltétel igaz, a második feltételt már nem szükséges kiértékelni, mert a teljes kifejezés biztosan igaz.

$admin = $true
$jogosultsag = $false

$hozzaferhet = $admin -or $jogosultsag

Ebben az esetben a teljes kifejezés igaz, mert az első feltétel igaz.

Igazként és hamisként értelmezett értékek​

PowerShellben egyes nem logikai értékek feltételes környezetben logikai értékként értelmeződhetnek.

Példák hamisként értelmezhető értékekre:

$false
$null
0
""
@()

Példák igazként értelmezhető értékekre:

$true
1
"szöveg"
@(1, 2, 3)

Példa:

$nev = ""

if ($nev) {
    Write-Host "Van név."
}
else {
    Write-Host "Nincs név."
}

Eredmény:

Nincs név.

Üres szöveg esetén célszerű lehet explicit ellenőrzést használni:

if ($nev -ne "") {
    Write-Host "Van név."
}

Vagy .NET metódussal:

if (-not [string]::IsNullOrWhiteSpace($nev)) {
    Write-Host "Van név."
}

Gyakorlati példa​

$kor = 17
$szuloiEngedely = $true

$belephet = ($kor -ge 18) -or $szuloiEngedely

Write-Host $belephet

Eredmény:

True

A kifejezés jelentése:

A felhasználó beléphet, ha legalább 18 éves,
vagy van szülői engedélye.

Másik példa több feltétellel:

$kor = 22
$aktivTagsag = $true
$tartozas = 0

$belephet = ($kor -ge 18) -and $aktivTagsag -and ($tartozas -eq 0)

Write-Host $belephet

Eredmény:

True

A feltétel akkor igaz, ha:

a kor legalább 18,
az aktív tagság igaz,
a tartozás értéke 0.
