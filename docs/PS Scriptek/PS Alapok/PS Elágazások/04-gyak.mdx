## Gyakorló példák `if-else` szerkezethez PowerShellben

---

### `-eq` → egyenlő

```powershell
$a = [int](Read-Host "Add meg az első számot")
$b = [int](Read-Host "Add meg a második számot")

if ($a -eq $b) {
    Write-Host "A két szám egyenlő."
}
else {
    Write-Host "A két szám nem egyenlő."
}
```

Ez a program azt vizsgálja, hogy a két szám ugyanaz-e.

Ha igen, akkor kiírja, hogy egyenlőek, különben azt, hogy nem egyenlőek.

---

### `-ne` → nem egyenlő

```powershell
$a = [int](Read-Host "Add meg az első számot")
$b = [int](Read-Host "Add meg a második számot")

if ($a -ne $b) {
    Write-Host "A két szám nem egyenlő."
}
else {
    Write-Host "A két szám egyenlő."
}
```

Ez a program azt vizsgálja, hogy a két szám különbözik-e.

Ha igen, akkor az `if` ág fut le, ha nem, akkor az `else`.

---

### `-gt` → nagyobb mint

```powershell
$a = [int](Read-Host "Add meg az első számot")
$b = [int](Read-Host "Add meg a második számot")

if ($a -gt $b) {
    Write-Host "Az első szám nagyobb."
}
else {
    Write-Host "Az első szám nem nagyobb."
}
```

Itt azt ellenőrizzük, hogy az első szám nagyobb-e a másodiknál.

Ha igen, akkor ezt kiírja, különben azt, hogy nem nagyobb.

---

### `-lt` → kisebb mint

```powershell
$a = [int](Read-Host "Add meg az első számot")
$b = [int](Read-Host "Add meg a második számot")

if ($a -lt $b) {
    Write-Host "Az első szám kisebb."
}
else {
    Write-Host "Az első szám nem kisebb."
}
```

Ez a példa azt vizsgálja, hogy az első szám kisebb-e a második számnál.

---

### `-ge` → nagyobb vagy egyenlő

```powershell
$a = [int](Read-Host "Add meg az első számot")
$b = [int](Read-Host "Add meg a második számot")

if ($a -ge $b) {
    Write-Host "Az első szám nagyobb vagy egyenlő."
}
else {
    Write-Host "Az első szám kisebb."
}
```

A `-ge` operátor akkor igaz, ha az első szám nagyobb, vagy pontosan ugyanannyi, mint a második.

---

### `-le` → kisebb vagy egyenlő

```powershell
$a = [int](Read-Host "Add meg az első számot")
$b = [int](Read-Host "Add meg a második számot")

if ($a -le $b) {
    Write-Host "Az első szám kisebb vagy egyenlő."
}
else {
    Write-Host "Az első szám nagyobb."
}
```

A `-le` operátor akkor igaz, ha az első szám kisebb, vagy pontosan egyenlő a másodikkal.

---

## Mire figyelj?

* Az `if` feltételét kerek zárójelbe kell írni.
* Az utasításokat kapcsos zárójelek közé kell tenni.
* Az `else` ág akkor fut le, ha a feltétel hamis.
* A változónevek elé `$` jelet kell írni.
* A `Read-Host` alapértelmezés szerint szöveget olvas be, ezért számoknál érdemes `[int]` típussá alakítani.
