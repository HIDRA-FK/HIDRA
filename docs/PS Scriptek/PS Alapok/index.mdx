# Alapok

Ez a fejezet a PowerShell alapvető nyelvi elemeit foglalja össze. A témakör célja, hogy a parancsok önálló futtatása után a tanuló értse a scriptlogika felépítéséhez szükséges alapfogalmakat is.

A fejezetben a hangsúly a változók, adattípusok, műveletek, bemenetek, kimenetek, feltételek, tömbök és ciklusok használatán van. Ezekre az ismeretekre később a rendszerüzemeltetési és automatizálási feladatok is épülnek.

:::info Hamarosan
A fejezet anyagai fokozatosan kerülnek feltöltésre.  
A későbbi leckékben a PowerShell alapvető programozási és scriptelési elemei szerepelnek majd.
:::

```text
tömbök és objektumok bejárása
egyszerű scriptlogika felépítése
````

## Változók és adattípusok

A PowerShellben a változók értékeket, objektumokat vagy parancsok eredményeit tárolhatják. A változók használata szükséges ahhoz, hogy egy script ne csak egymás után futó parancsokból álljon, hanem adatokat is kezeljen.

A fejezetben előkerülnek például az alábbi témák:

```text
változó létrehozása
értékadás
változó értékének módosítása
típus lekérdezése
típuskonverzió
szöveg, szám és logikai érték kezelése
tömbök és hashtable-ök használata
```

Példa:

```powershell
$nev = "Kiss Anna"
$kor = 18
$aktiv = $true
```

A változók később feltételekben, ciklusokban, fájlműveletekben és automatizált scriptekben is megjelennek.

## Műveletek és operátorok

A scriptlogikához szükség van aritmetikai, összehasonlító és logikai műveletekre.

A fejezetben szerepelnek többek között:

```text
összeadás
kivonás
szorzás
osztás
maradékképzés
kerekítés
számok összehasonlítása
szövegek összehasonlítása
logikai ÉS, VAGY, NEM műveletek
```

Példa összehasonlításra:

```powershell
$kor -ge 18
```

Példa logikai kifejezésre:

```powershell
($kor -ge 18) -and $aktiv
```

Ezek a műveletek adják az elágazások és ciklusok feltételeinek alapját.

## Bemenet és kimenet

A PowerShell scriptek gyakran adatot kérnek be a felhasználótól, majd eredményt írnak ki a konzolra vagy fájlba.

A fejezetben szó lesz például:

```text
Read-Host használatáról
Write-Host használatáról
Write-Output szerepéről
változók szövegbe illesztéséről
beolvasott értékek konvertálásáról
kimenet fájlba mentéséről
```

Példa:

```powershell
$nev = Read-Host "Add meg a neved"

Write-Host "Szia, $nev!"
```

Fontos különbség, hogy a `Write-Host` közvetlenül a konzolra ír, míg a `Write-Output` feldolgozható kimenetet ad tovább a pipeline-ba.

## Elágazások

Az elágazások segítségével a script különböző feltételek alapján eltérő utasításokat hajthat végre.

A későbbi leckékben szerepelni fog:

```text
if szerkezet
elseif ág
else ág
összetett feltételek
logikai operátorok feltételben
switch szerkezet
```

Példa:

```powershell
$kor = 18

if ($kor -ge 18) {
    Write-Host "Nagykorú."
}
else {
    Write-Host "Nem nagykorú."
}
```

Az elágazások teszik lehetővé, hogy a script ne mindig ugyanazt hajtsa végre, hanem a bemenetek és az aktuális állapot alapján döntsön.

## Tömbök és hashtable-ök

A tömbök több érték tárolására használhatók. A hashtable kulcs-érték párok kezelésére alkalmas.

Példa tömbre:

```powershell
$nevek = @("Anna", "Béla", "Csaba")
```

Példa hashtable-re:

```powershell
$diak = @{
    Nev = "Kiss Anna"
    Osztaly = "13A"
    Jegy = 5
}
```

A fejezetben később szerepelni fog:

```text
tömb létrehozása
tömb elemeinek elérése
tömb elemszámának lekérdezése
tömb bejárása
hashtable létrehozása
kulcsok és értékek kezelése
```

Ezek az adatszerkezetek különösen fontosak akkor, ha több fájlt, több felhasználót, több rekordot vagy több parancseredményt kell feldolgozni.

## Ciklusok

A ciklusok ismétlődő műveletek végrehajtására szolgálnak. Segítségükkel ugyanazt a műveletet több adaton vagy több alkalommal lehet végrehajtani.

A fejezetben szerepelni fog:

```text
foreach ciklus
for ciklus
while ciklus
do while ciklus
tömbök bejárása
parancseredmények feldolgozása ciklussal
```

Példa:

```powershell
$nevek = @("Anna", "Béla", "Csaba")

foreach ($nev in $nevek) {
    Write-Host $nev
}
```

A ciklusok az automatizáció egyik alapját adják, mert lehetővé teszik sok elem azonos szabály szerinti feldolgozását.
